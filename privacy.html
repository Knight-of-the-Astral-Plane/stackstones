PRIVACY & CREDITS

Built for balance.

Playing

No account is needed. The game keeps your personal best and training progress in your browser’s local storage. These stay on your device. We do not add analytics, advertising, tracking cookies or a persistent online player ID. Fonts, images and audio are served with the game.

Sharing a score

Sharing is voluntary. When enabled, pressing Submit sends your chosen alias, stone count and a random code for that run to the score service. Only your alias, rank and stone count are shown on the leaderboard. The run code prevents duplicate entries from a retry; it is not a permanent player identifier. Only a hash of that code is kept in the ranking file.

The live Top 100 is kept in a small JSON file in managed Cloudflare storage. A public snapshot is also kept in the game’s GitHub repository. Public aliases and scores may remain in Git history after leaving the Top 100. Use a pseudonym rather than your real name or email address. Scores are submitted by the browser and are not independently verified.

Hosting

GitHub Pages and the ranking service may process connection details such as IP addresses for operation and security. The game itself does not add IP addresses to the ranking file. See GitHub’s privacy statement and, Cloudflare’s privacy policy.
