# Stack Stones

The sky is not the limit.

A browser game about balance, stones and unreasonable ambitions. Includes the Meadow homepage, the game, a World Top 100 leaderboard and privacy information.

Publish with GitHub Pages from the `main` branch, repository root.

The game files preserve the approved physics. Fonts, images and audio are stored in `assets/`; the homepage loads the game when Play is selected.
